# references/discipline.md · P0/P1/P2 三级纪律全文

> 任何使用本 Skill 的 Agent / 用户必须逐级理解这些纪律。
> 违反 P0 = 阻断级返工，不得交付。
> 违反 P1 = 警告级，须如实记录并可追溯，不阻断交付。
> 违反 P2 = 行业包级，参见 `packs/<行业>/RULES.md`。

---

## P0 · 阻断级（违反即返工，不得交付）

### 1. 禁止编造

- **拿不到就标「本期无法获取 / —」**
- 专题未取得招股书 → 填「未取得招股书」
- 不得用模糊占位（"以招股书为准"、"约"、"大约"）
- 不得用次级源冒充权威源

### 2. 重新采集不沿用

- 时点型数据按月全量重采完整枚举
- 不得沿用上月"在审 N 家"、"辅导备案 M 家"等计数
- 不得按记忆写标的池

### 3. 工具实测先于标 ✅

- 所有 MCP / HTTP / agent 通道必须先 smoke test 实测一次
- 未实测**只能**标 🟡
- 不得用"配置里写了"代替实测

### 4. 来源逐条标注

- 正文「来源：机构 + 日期」
- 表格「数据来源 + 截至」
- `溯源.jsonl` 数值类带锚点（source_key + source_field 或 source_row + source_field）
- url-only 记录不参与回读但认可为出处

### 5. 数值回读通过

- `verify_value.py` 无 ❌（月报数字 = 源文件数字）
- 差 10/100/10000 倍量级 → 报"单位量级疑似不一致"
- 币种+数量级复合单位用最长匹配（`亿美元` ≠ `亿元`）

### 6. 名单 / 异常有交代

- 环比 ±50% 必须在变更摘要逐条点名
- 新增/移除标的必须在变更摘要逐条点名
- `reasonableness_check.py` 无 ❌

### 7. 盲审通过

- 独立盲审（子 Agent）无阻断级问题
- 复审必须换新审核 Agent（不允许同一 Agent 复审自己）
- 子 Agent 失败 ≥2 次降级 mainagent 对抗性自查 + 标注「独立性受损」

### 8. 格式对齐 ≥95%

- `format_diff.py` 相似度 ≥ 0.95（结构变化不计）
- 含图表报告 + 表格图注由人工复核

### 9. 空值必补

- `diff_empty.py` 抓"旧有值 → 新空值"，非空则必补
- 业务键对齐（默认首列，禁用序号）
- 字段缺值 → `qcc` 工商核实，不得用"查证不稳就填 -"

### 10. 口径漂移暂停

- `snapshot.py diff` 深 diff ≥3 项必须暂停
- 显式请求用户确认后才能继续
- 变更摘要列差异项

### 11. 产出必达工作区

- Step 9.5 必须执行 `archive_to_workspace.py`
- 全产出须出现在使用者**当前对话工作区**
- 不得只留在 skill 基目录 `runs/` 内
- 违反即视为未交付

## P1 · 警告级（须如实记录并可追溯，不阻断交付）

### 1. 一次性确认

- 必填 ≤5 条
- 确认结果落盘 `runs/<run-id>/input/用户确认.md`

### 2. 字段口径一致

- 同一字段全表统一
- 法人统一工商法人名（如某公司 CEO 字段统一用工商法人，不混用创始人/天使投资人等）

### 3. 时点统一

- 按 `时点对齐策略.yaml` 对齐各来源时点
- 首页脚注写明采集日 + 目标时点

### 4. 财报期双轨

- 源文件标期
- 正文表格脚注

### 5. 差距如实报告

- TOC 需 F9
- 图表未更新
- 数据源无接口
- 子 Agent 失败
- 必须明确告知，不得隐瞒

### 6. 通道降级全月报可追溯

- 正文"数据来源"段显式引用本期实际生效通道与降级链
- 不得只在变更摘要写

### 7. 每表对应章节 + 具体来源

- 源文件命名规范：`下载资料/<章节>-<具体来源>.csv`
- 交叉验证标注冲突 + 采用源 + 理由

### 8. 归档完整

- `runs/<run-id>/` 六件套
- 运行日志 + 通道降级日志
- `metrics.py record` 记录本期质量指标

## P2 · 行业包级

行业包专属纪律写在 `packs/<行业>/RULES.md`。通用兜底纪律见 `packs/_default/RULES.md`。

### 跨行业通用兜底纪律（_default）

1. 金额单位同表统一（万元/亿元/美元/港元不允许同表混用）
2. 财报期双轨（源文件标期 + 正文表格脚注）
3. 拿不到就标「本期无法获取 / —」
4. 未知赛道由用户拍板（不做赛道假设）

### 具体赛道示例（机器人）

1. **港股 6 个月有效期剔除**：港股在审条目凡首次递表超过 6 个月未聆讯的，必须加 `是否仍在 6 个月有效期内` 列
2. **美股 S-1/SPAC 分类**：申报严格指 S-1/Form F-1 路径；SPAC 合并、直接直接上市、Form 425 业务合并须单列
3. **卖方研报一致预期独立化**：出货量/市占率等预测数字须以"卖方一致预期小表"呈现
4. **一级市场融资金额口径**：公告披露口径优先；媒体与公告冲突以公告为准

## 纪律的边界（如实告知，不伪装）

- 纪律是"对开发期"约束，不是"对成品期"审查
- 任何门禁脚本都有边界：`format_diff` 不覆盖视觉差异、`verify_value` 不验证源文件本身等
- 盲审作为兜底，但盲审 ≠ 全部门禁 —— 门禁在前盲审在后
