# _default 兜底行业包 · 行业专属纪律（P2 级 · 通用兜底）

> 本文件承接 SKILL.md 纪律分级的 P2 层。**只写跨行业通用、无赛道假设的硬性规则**。
> 具体赛道的特殊纪律（人形机器人 / 协作机器人 / 港股 6 个月有效期剔除 / 美股 S-1 分类等）必须写在 `packs/<新行业>/RULES.md` 中。
> 通用纪律（禁止编造/重新采集/溯源锚点/格式保真等）在 SKILL.md 的 P0/P1 层，不重复。

## 一、数据字段与单位

1. **金额单位同表统一**：万元 / 亿元 / 美元 / 港元不允许同表混用。
   - 港股 → 默认港元（HKD），必要时标注「港币」
   - A 股 → 默认人民币（CNY），必要时标注「人民币」
   - 美股 → 默认美元（USD）
   - 募资金额默认「公司公告披露口径」，并在源文件标注
2. **百分比口径**：环比/同比/市占率等百分比字段小数位统一（推荐 1-2 位）
3. **日期口径**：公告日 ≠ 官网更新日 ≠ 媒体转载日；正文中需明确口径来源

## 二、表格与正文

1. **正文计数 = 表格行数**：每处「共 N 家/条/笔」必须与对应表格行数一致（cross_consistency 门禁硬约束）
2. **章节+具体来源**：每张表格的源文件命名必须遵循 `下载资料/<章节>-<具体来源>.csv` 规范
4. **数据来源行**：表格下方必须有「数据来源」一行（含截至日期）

## 三、跨月复用的最低要求

1. **首次使用必须落盘快照**：`python scripts/snapshot.py snapshot --ym <YYYY-MM> --run-id <run-id>`
2. **任何 YAML 修改必须带 version 字段递增**：禁止裸改
3. **新增字段先改 schema 再改值**：`采集清单.yaml` / `口径字典.yaml` 的 schema 在 `templates/` 中

## 四、跨月去重

1. **本期候选 vs 上月报告逐条比对**：转载合集（如行业月报集合）会把上月事件转载进本月
2. **公告日 vs 转载日**：以**公告日**作为去重时间锚点，±45 天窗口
3. **公司全名 + 子串匹配**：跨月去重脚本 `cross_month_dedup.py` 默认全名/子串匹配

## 五、专题对比

1. **业务模式同构**：专题对比公司必须业务模式同构（整机 vs 整机、零部件 vs 零部件），不同构禁止对比
2. **招股书 PDF 不可获取**：填「未取得招股书」并降低该行信息密度，禁止「以招股书为准」占位
3. **专题数据回填**：专题表的关键数字必须回填月报源文件，避免"两份不同口径的数字"

## 六、瞎补的常见反模式（严禁）

- ❌ 看到"旧月报是 N 家"就沿用 N，不重采 → **重新采集不沿用**（P0）
- ❌ 用 `cell.text = value` 改写表格 → **必须用 docx_utils.set_cell_keep / set_para_keep**（P0）
- ❌ 通道未 smoke test 就标 ✅ → **未实测只能标 🟡**（P0）
- ❌ 月报数字 = 源文件数字不一致 → **数值回读硬伤**（P0）
- ❌ 环比 ±50% 没有在变更摘要逐条点名 → **合理性门禁硬伤**（P0）
- ❌ archive_to_workspace.py 没跑就交付 → **未交付**（P0-11）
