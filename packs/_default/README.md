# packs/_default · 通用兜底行业包

> **适用**：任何无法明确归入特定垂直赛道、需要"先有个能跑的骨架"的场景。
> **限制**：本包不含具体标的池，仅作为**反推起点**——运行 `python scripts/pack.py wizard 旧月报.docx --name <新行业>` 由 Agent 反推新行业包骨架。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `RULES.md` | 兜底行业纪律（跨行业通用，详见 SKILL.md P0/P1） |
| `口径字典.yaml` | 字段命名 / 统计窗口 / 币种 / 单位（待激活后人工补完） |
| `采集清单.yaml` | 采集项列表（含类型：时点型/半结构型/结构型） |
| `权威源映射.yaml` | 字段维度权威源 + 通用降级链 |
| `时点对齐策略.yaml` | 各源数据时点 → 目标时点对齐策略 |
| `标的池.yaml` | 赛道白名单（_default 为空，由 wizard 反推） |

## 升级到具体行业

```bash
# 步骤 1：用旧月报 docx 反推行业骨架
python scripts/pack.py wizard 旧月报.docx --name medtech

# 步骤 2：人工补完 packs/medtech/ 下的 5 个 YAML（wizard 会留 TODO 标记）
#   - 标的池.yaml：赛道白名单（逐家人工判断是否属于赛道）
#   - 口径字典.yaml：字段命名/币种/单位
#   - 采集清单.yaml：每条采集项的通道 + 类型
#   - 权威源映射.yaml：本赛道特有的字段维度权威源
#   - 时点对齐策略.yaml：本赛道特有的跨源时点对齐规则

# 步骤 3：激活新行业包（自动备份旧 config/ 到 config/_backup/）
python scripts/pack.py activate medtech

# 步骤 4：落盘本期快照
python scripts/snapshot.py snapshot --ym 2026-09 --run-id <run-id>
```

## 兜底包的纪律（P2 级）

仅跨行业通用纪律：
1. **金额单位同表统一**：万元/亿元/美元不允许同表混用；港股默认港元，A 股默认人民币。
2. **财报期双轨**：源文件标期 + 正文表格脚注。
3. **拿不到就标「本期无法获取 / —」**：禁止编造。
4. **未知赛道由用户拍板**：本兜底包不做赛道假设，由 Step 4 用户确认清单显式指定。

具体赛道的特殊纪律（如机器人的"港股 6 个月有效期剔除"）必须写在 `packs/<新行业>/RULES.md` 中。
